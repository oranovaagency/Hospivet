# Hospivet · Liens

Page de liens de la clinique vétérinaire **Hospivet**.
C'est la page qui s'ouvre quand on touche la plaque ou la carte NFC, ou qu'on scanne leur QR code.

**Adresse en ligne :** https://oranovaagency.github.io/Hospivet/

> Le dépôt doit s'appeler exactement `Hospivet` : cette adresse est imprimée dans le QR code de la plaque et de la carte.

**Avant de mettre en ligne :** remplir `CLINIC` dans `index.html` (téléphone, WhatsApp, réseaux, Google Maps, avis). Un bouton laissé vide ne s'affiche pas.

Hébergement : GitHub Pages → Settings → Pages → *Deploy from a branch* → `main` / root.

Réalisé par Oranova.
